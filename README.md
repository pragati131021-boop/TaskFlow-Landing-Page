## 🎯 Intended Users
TaskFlow is designed for college students, freelancers, and small remote teams who require an intuitive, clutter-free workspace to track assignments, manage daily tasks, and coordinate project deadlines without excessive overhead.

---

## 🎨 Design System & Rationale
- **Color Choices:** 
  - *Calm Emerald & Forest Accents:* Conveys focus, clarity, and reliability while reducing visual fatigue during long work sessions.
  - *Clean Slate & Off-White Background:* Ensures optimal contrast and a clean hierarchy.
- **Typography:** 
  - *Modern Sans-Serif:* Crisp legibility across all screen sizes and resolutions.
- **Components & Layout:** 
  - Built using responsive structure: Top Navigation Bar, Hero Section with CTA, 3 distinct Feature Cards, and Footer.
  - Reusable components configured for cards and buttons.
